# 四级精练 · Codex 本地插件 0.2.0

在对话旁按部分刷四级真题，划词、标记、记笔记，再把积累整理成一条消息讨论。米白纸面，正文默认 17px，可调大。支持多试卷导入，原卷和旧学习记录继续保留。

## 导入新试卷

1. 打开“四级精练”，点顶部“导入试卷”。
2. 选择 PDF；或填写 CET-4 学习目录内的 PDF 路径。
3. 点“识别并预览”，核对试卷编号、标题、题干、选项、段落和识别提示。正文按部分展开，参考答案隐藏在原文/高级编辑中。
4. 如需修正，点“交给助手核对”，助手读取导入草稿与原文后可更新识别结果；回到面板点“刷新识别预览”。也可以展开高级编辑手工修正，再点“更新预览”。
5. 亲自核对后勾选确认，点“加入试卷库并打开”。之后从顶部试卷下拉切换。

没有参考答案也能练习，会明确提示不自动判分。遇到缺题、重复题号、选项残缺等问题，先修正再导入。相同试卷编号不会覆盖原卷或已有记录。当前每次最多 30MB / 60 页；扫描件使用本机 Tesseract 中英文 OCR，首次或多页识别较慢，版式复杂时需要助手核对，不能保证任意 PDF 自动准确识别。听力音频须另行提供。

识别预览会保留在本机，但尚未加入正式试卷列表。只有用户确认后才加入。结构检查不替代逐题内容核对；没有识别到的题目和答案不会猜补。未读清楚时可向助手提供原卷页面作进一步核对。

## 刷题

- 顶部切试卷，再切写作、听力、阅读或翻译及具体小节。
- 选择题作答自动保存；写作和翻译草稿离开输入框时保存，也可手动点保存。
- 参考答案默认隐藏，只核对当前小节；无答案的题目明确提示。
- 划选原文，工具条可选标记、单词、短语、句子、加入讨论、记笔记。
- 待讨论中补充自己的理解，整理消息后手动发送；条目继续保留。
- 标记有稳定编号，可在笔记或聊天中引用，支持定位原文。黄色为用户，浅绿色为助手。
- 点“存入两张生词表”，单词和短语追加到已有文件并去重；自己的猜测不自动作为释义。句子保存在该卷笔记中。

## 数据保存

学习根目录默认 `/Users/liu/CET-4`，可通过 `CET4_ROOT` 指定。各卷答案、草稿、标记、笔记和待讨论独立，两张生词表跨卷共用。

| 内容 | 相对学习根目录的位置 |
|---|---|
| 原内置卷存档（原位保留） | `.codex-study/state.json` |
| 新卷存档 | `.codex-study/exams/<卷号>/state.json` |
| 导入后试卷、源 PDF、提取原文 | `.codex-study/library/<卷号>/` |
| 尚未确认的识别草稿 | `.codex-study/imports/<导入编号>/` |
| 每卷自动导出的笔记 | `.codex-study/<卷号>-笔记.md` |
| 共用生词表 | `不会的单词表.csv`、`不会的短语表.csv` |

自动导出的笔记请在面板编辑；手工补充另存文件。状态损坏时拒绝覆盖，多个进程写入通过根目录锁串行处理。异常退出留下锁时，应先关闭相关服务，再移除 `.codex-study/write.lock`。

## 助手接口

`open_study` / `read_study` 可选 `examId`，省略时返回原内置卷，并附带完整试卷目录。保存操作通过 `study_action`：

- 原有答题、草稿、标记、笔记、收词等操作在 `args.examId` 中明确指定试卷；省略时仍指向旧卷，兼容旧界面。
- `import_preview`：传 `path`（学习目录内）或 `pdfBase64` + `filename`，提取并保存待确认草稿。
- `import_read`：传 `importId`，读取草稿、检查结果和原文。
- `import_update`：传 `importId` 和完整的 `paper` 对象，更新识别结果并重新检查。不得猜补缺失内容。
- `import_commit`：仅在用户核对确认后传 `importId`、`confirmed: true`，正式加入试卷库。

标记位置为原文块 `blockId` 与 JS UTF-16 `start/end` 下标；`text` 必须与位置完全一致。助手写标记或笔记时 `by=assistant`，`note.refs` 可引用标记编号。

## 安装与检查

本机使用兼容入口 `.codex-plugin/plugin.json` + `.mcp.json`。便携清单保留为 `plugin.portable.example.json`，不作运行入口；此前同时使用根 `plugin.json` 时，当前宿主只读到元数据而未加载 MCP 服务。

更新后请关闭再开启“四级精练”，并重新打开面板，以载入新工具参数和新版本界面。

```sh
node --test tests/*.test.mjs
node tests/verify-codex-host.mjs
CET4_ROOT=/path/to/test-data node server.mjs --preview
```

Node.js 20+，服务没有 npm 依赖。文本提取依赖本机 Poppler 的 `pdfinfo` / `pdftotext`；OCR 依赖 `pdftoppm`、`tesseract` 及 `eng` / `chi_sim` 语言包，默认路径为 `/opt/homebrew/bin/`。本机已检测到这些工具。预览模式实际保存到指定测试目录，聊天消息使用复制方式。
