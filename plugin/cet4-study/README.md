# 四级精练（CET-4 Practice）

DeepSeek Harness 的一个本地插件：把一份四级真题按部分放进右侧栏，边刷题边标记、记笔记，
把不认识的单词／短语／句子收进待发布篮，最后一次放进对话框，并写进工作区的两张生词表。

- 左侧栏没有变化；练习内容出现在**右栏**，聊天窗口仍在左边，可以对照着问。
- 界面为米白色纸面配色（深色主题时自动转深色），字号跟随 Harness 的正文大小设置。
- 所有数据都在本机：题目 JSON 在插件目录，笔记与标记在 `.state/`，生词表在仓库根目录。

## 怎么打开

两种入口，任选：

1. 点聊天标题栏最右侧的「展开右栏」按钮（或在右栏已折叠时点它），右栏的 + 号→指南里点
   **四级精练**；
2. 输入框工具条上的 **四级** 按钮，直接展开右栏并打开面板。

第一次打开会读取 `2025-12-1` 这份卷子。

## 界面上有什么

顶部一行：标题、试卷选择、五个页签（刷题／笔记／标记／生词／待发布）、显示答案。

- **刷题**：上方「I 写作 / II 听力 / III 阅读 / IV 翻译」切部分，部分内再切小节
  （选词填空／段落匹配／仔细阅读）。听力、阅读选择题点选项即记录答案；词库题先点空格再点词；
  段落匹配用下拉选段落字母；写作与翻译是自动保存的草稿框（写作显示词数）。
  「显示答案」给当前小节判对错。
- **标记**：每题右上角可以标记/取消；「标记」页签是清单，点一行直接跳到那题。
- **笔记**：按当前小节记账；可以「引用…」一处标记，笔记里会带上引用的题号与文字。
- **生词**：两张表当前的内容。
- **待发布**：收集来的内容，可逐条补自己的理解，然后：
  - **整理后放进对话框**：把整篮内容合成一条消息写进输入框，检查后回车发送；
  - **存入生词表**：把单词／短语写进 `不会的单词表.csv`、`不会的短语表.csv`（已存在的会跳过）。

### 收词

在正文里拖选文字，松手后出现小浮条：**单词／短语／句子**。点一下即收进「待发布」，
并带上出处（哪个部分、第几题）。句子只进对话框，不写进两张单词表。

## 数据放在哪

| 内容 | 路径 |
|---|---|
| 结构化试卷 | `content/exams/<卷号>.json` |
| 答案、标记、笔记、草稿、待发布 | `.state/study-state.json` |
| 客户端事件诊断（仅 40 条） | `.state/client-events.json` |
| 单词表 / 短语表 | 仓库根目录 `不会的单词表.csv` / `不会的短语表.csv` |

`.state/` 已在仓库 `.gitignore` 里，不会进版本库；两张生词表是可以提交的学习资料。

## 换一份卷子

插件只认结构化 JSON。把新卷子（PDF 也行）放到仓库里，让 Harness 里的助手按同一套字段
生成 `content/exams/<卷号>.json`，面板的试卷下拉里就会出现它。字段见
`content/exams/2025-12-1.json`；`content/validate.mjs` 会校验题目编号与答案。

## 开发

`src/*.js` 是源码，按文件名顺序拼成单文件浏览器包：

```sh
node build.mjs      # 生成 client.js
node --check client.js
```

改完 Host 半（`index.js`）或重新生成 `client.js` 后，重新加载插件才会生效：

```sh
# 在 Harness 里（或用插件管理面板）关闭再开启 cet4-study
```

面板本身没有独立构建步骤：`client.js` 里就是 `window.__ModuleLoader__` 工厂。

## 已知限制

- 音频不在仓库里，听力部分只能当阅读题练、对答案，不能听写。
- 生词表是 Markdown 表格形式；需要排版版可以再让助手编译成 PDF。
- 面板只读 `content/exams/` 下已有的卷子；识别新卷子要过一次结构化（助手可做）。
