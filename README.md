## 作文练习顺序

先独立完成初稿，再检查切题、内容、结构与语言。修改时保留初稿，说明具体改动；最后从实际写过的句子中积累可替换的表达，注明使用条件。当前已完成作文初稿 01 的评改，并在 PDF 中补充逐句解释与可复用结构。

## 四级精练插件（Harness 右栏）

`plugin/cet4-study` 是装在本机 Harness 里的插件：右栏打开 `2025-12-1` 这份卷子，按部分刷题、
标记、记笔记，把划选的单词短语收进待发布篮，一次放进对话框，并写进根目录的两张生词表。

- 打开方式：聊天标题栏最右的「展开右栏」→ 指南卡「四级精练」，或输入框工具条上的「四级」按钮。
- 使用说明与数据结构：[plugin/cet4-study/README.md](plugin/cet4-study/README.md)
- 生词表采用 CSV 格式，可在 GitHub 直接查看：[不会的单词表.csv](不会的单词表.csv)、[不会的短语表.csv](不会的短语表.csv)

插件运行时状态写在 `plugin/cet4-study/.state/`（已忽略），不进入版本库。
